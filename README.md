## 踩过的坑

- GitHub 的 22 端口在国内经常被封，改用 `ssh.github.com:443` 就能连上
- Git Bash 里不要手打中文路径，用 Tab 补全；`cd` 后面也不能放 `*`
- `D:\deepseek` 是 DeepSeek 客户端安装目录，练习文件一律放进 `工作区` 子目录
